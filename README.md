# Student Study Planner

A beginner-friendly student project built with HTML, CSS, and vanilla JavaScript.

## Features
- Add study tasks and assignments
- Set subject, due date, priority, and planned study duration
- Mark tasks complete or pending
- Delete tasks and filter the task list
- Dashboard statistics and completion progress bar
- Save tasks in browser local storage
- Responsive layout for desktop and mobile

## Run the project
1. Download and extract the ZIP file.
2. Open the `student-study-planner` folder.
3. Double-click `index.html` to open it in a modern browser.

No installation or server is required for this demo.

## Project structure
```text
student-study-planner/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Important note
This is a front-end demo, not a complete cloud SaaS service. Tasks are stored in the current browser only. For a production SaaS app, add a backend API, a database, secure authentication, and per-user authorization. Never store plain-text passwords.
